# macrosnap-legal

Public privacy + terms for the MacroSnap iOS app, served via GitHub Pages.

- [Privacy](https://andrewmkim.github.io/macrosnap-legal/privacy.html)
- [Terms](https://andrewmkim.github.io/macrosnap-legal/terms.html)

Source of truth lives in the private app repo under `docs/legal/`; this repo
mirrors them as Jekyll-rendered HTML for App Store + TestFlight submission.
